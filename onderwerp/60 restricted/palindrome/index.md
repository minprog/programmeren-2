# Palindrome

1. Schrijf een keurige `Stack`-class met type hints en uitgebreide tests. Elke test moet een deel van het gedrag van de class testen (bijvoorbeeld dat de LIFO-eigenschap te allen tijde correct wordt aangehouden).

2. Schrijf een keurige `Queue`-class met type hints en uitgebreide tests. Elke test moet een deel van het gedrag van de class testen (bijvoorbeeld dat de FIFO-eigenschap te allen tijde correct wordt aangehouden).

3. Neem de Palindrome-code uit het boek over en probeer deze uit met jouw `Stack` en `Queue`. Pas eventueel je eigen classes en tests aan om ze passend te maken bij de code uit het boek.
