# Linked structures

Je gaat om te beginnen leren over de precieze werking van variabelen, namen en referenties: het *geheugenmodel* van Python. In Python gaat er een hoop automatisch, maar als je zelf datastructuren gaat manipuleren en bouwen kun je makkelijk tegen bugs aanlopen. Met een goed begrip van het geheugenmodel ziet je sneller wat het probleem is.

Dan ga je aan de slag met lijsten. Er zijn diverse strategieën om lijsten bij te houden in een programmeertaal. Je kent uit C nog *arrays*, dat zijn blokken geheugen waarin meerdere elementen direct achter elkaar staan. Het is flexibeler en soms zelfs efficiënter om elk element uit een lijst op een losse plek te hebben staan, met verwijzingen tussen de elementen: een *linked list*.

Dan weet je zoveel over de verschillende structuren in Python dat we je een challenge geven: je krijgt een complete werkende Sudoku-solver en jij gaat aan de slag met een *profiler* om de punten in de code te vinden waar deze solver inefficiënt werkt. Met je kennen van datastructuren en Python kun je optimalisaties doen en de solver heel snel laten werken.

## Puntentelling

List structures
: 2 punten voor een goedwerkende en complete uitwerking, geen deelpunten

Profiling
: 1/4 punt per goed onderbouwde concrete optimalisatie, met een maximum van 2 punten
