# Python

Het doel van deze module is jouw bestaande programmeerkennis over te dragen naar een nieuwe taal, Python. Dat doe je door veel kleine programma's en functies uit te werken. Je kan vaak beginnen met de gedachte, "hoe zou ik dat doen in C?" en vervolgens, "hoe ziet dat eruit in Python?"[^1].

[^1]: Heb je wél al ervaring met Python, dan ga je deze module kennis maken met een heel specifieke stijl van programmeren. Bestudeer de voorbeelden en volg de instructies goed: het is niet de bedoeling dat je alles op de automatische piloot doet, zoals je eerder gewend was.

De verschillende opdrachten zijn bewust kort en praktisch zonder uitleg. Dat betekent dat je zelf en *het liefst samen* op onderzoek uit moet gaan. Daag jezelf en elkaar hierbij uit, want de opdrachten zijn zo gekozen dat er vaak slimmere, meer "Pythoneske" manieren zijn om ze op te lossen.

De assistenten zijn minder behulpzaam bij deze module. Het is echt aan jou en je mede-studenten om uit te vogelen hoe Python in elkaar steekt. Dit is een passende uitdaging als je Programmeren 1 netjes gehaald hebt. Natuurlijk mag je wel altijd om hulp vragen, maar doe dit eerst bij je medestudenten.

> Bij deze module is samenwerken dus de bedoeling! Het is wel essentieel dat je aan het eind van de week kunt stáán voor je eigen uitwerkingen en dat je je ingeleverde werk in detail kunt uitleggen. Gebruik de module dus om per opdracht steeds zelfstandiger te worden.

## Leerdoelen

Je gaat in deze module:

- De basis van Python onder de knie krijgen
- Oefenen met lists en strings in kleine opdrachten
- Tests schrijven voor je eigen code
- Werken met tools die kwaliteit checken

Onthoud wel: Python is niet het doel van deze cursus, maar alleen maar de taal die we gebruiken om je de andere onderwerpen aan te leren. Al tijdens deze module focussen we op testing en documentatie, en in de komende modules gaan we de onderwerpen snel uitbreiden.

## Puntentelling

Iedere goedwerkende opdracht is een halve punt waard tot een maximum van 6 punten. Er zijn 14 opdrachten in totaal, dus je hoeft er maar 12 te maken voor het volledig aantal punten.

## Steropdrachten

Er zijn daarnaast 2 opdrachten met een `*`. Deze opdrachten tellen gewoon mee, maar we markeren ze apart omdat ze wat uitdagender zijn. Lever je deze opdrachten allebei goedwerkend in, dan is dat samen één extra punt voor deze module. Zie ook studiewijzer voor uitleg over steropdrachten.
